# agent-security-demo (INTENTIONALLY INSECURE)

A small set of AI agents, MCP servers and Claude Code settings with deliberate security issues, used
to demonstrate [Agenquell](https://github.com/agenquell-labs) audits, GitHub checks and code scanning.

Every issue here is deliberate. All credentials are fake and do not belong to any real account.
Never deploy this code.

Audited on every push by the Agenquell GitHub App (checks on commits and pull requests).
Results are also uploaded to GitHub code scanning (Security tab).
